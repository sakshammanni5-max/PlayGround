StreamApp

Screen livestreaming for YouTube — built for BGMI gameplay

Native Android app (com.streamapp) that captures the phone screen, encodes with hardware MediaCodec via RootEncoder 2.8.1, mixes game + microphone audio, and pushes RTMP to YouTube Live — controlled from a persistent floating bubble over the game.

Core workflow

  1. Connect the YouTube account (genuine Google OAuth, youtube scope only).
  2. Configure title, description, privacy (Public / Unlisted / Private), Made-for-Kids flag.
  3. Pick 480p / 720p / 1080p, 30 / 60 / experimental 90 FPS, portrait or landscape.
  4. Go live now, or schedule an event (Android still needs one-tap capture approval at air time).
  5. Grant screen-capture consent, 3-second countdown, floating bubble appears.
  6. Leave the app, play BGMI, toggle mic without killing game audio, stop cleanly from the bubble.

Streaming engine

  • MediaProjection screen capture + RootEncoder GenericStream RTMP
  • Correct YouTube lifecycle: broadcast → stream → bind → wait active → transition live
  • Broken-pipe diagnosis, bounded reconnects (max 3), no silent quality drops
  • 90 FPS is experimental: encoder rejection falls back to 60 FPS and says so

Audio & bubble

  • Independent sources: internal/game audio + microphone (mix volume control)
  • Mic OFF never stops game audio, video, or RTMP — no session restart
  • Draggable overlay bubble: live status + elapsed time, mic toggle, mic-privacy shield lock, settings, two-tap stop

YouTube API

  • Real Data API v3: broadcasts, live streams, binding, thumbnails
  • Thumbnail picker with JPEG/PNG, ≥640×360, ≤2 MB validation and real upload result
  • Quota / network / auth errors surfaced honestly; secrets never logged
